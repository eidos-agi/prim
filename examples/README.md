# Prim Examples

This directory holds illustrative and reference material for the Prim category.

Domain-specific examples live primarily in the profile repositories. This folder provides:

1. A minimal conceptual Prim (category-level illustration)
2. Pointers to real profile examples (OCSF, ORF, etc.)

## Principle

Examples should reinforce:

- The Prim is the source of truth
- Views are generated or projected
- Evidence and structure are first-class
- Humans and agents can both inspect the same pack
