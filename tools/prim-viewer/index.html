prim-viewer · surface / talk · cites * · webmcp

Drop a .prim

Same idea as Flash. The file is the thing. This tag is how you see it. A model talks to it through WebMCP.

<show-prim filename="yadda.prim">

React

import { ShowPrim } from "@eidos-agi/prim-viewer/react"

<ShowPrim filename="yadda.prim" />

Next.js

import { ShowPrim } from "@eidos-agi/prim-viewer/next"

export default function Page() {
  return <ShowPrim filename="yadda.prim" />
}

WebMCP

prim-status · prim-open · prim-tab · prim-files · prim-face · prim-read

The tag registers these on document.modelContext.
A model talks to the prim. It does not scrape the page.

await document.modelContext.executeTool("prim-tab", { tab: "color" });
